# NeoStrike - Local Multiplayer Android Test Project

مشروع Android مستقل بالكامل لاختبار الاتصال والـ Multiplayer عبر الشبكة المحلية (Local LAN / Wi-Fi / Hotspot) بدون الحاجة لأي اتصال بالإنترنت وبدون خوادم سحابية.

## مميزات المشروع
1. **آلية اكتشاف تلقائية عبر الشبكة المحلية (Zero-Config Discovery):**
   - يدعم **Android NSD / mDNS** عبر `NsdManager` بنوع الخدمة `_neostrike._tcp.`
   - مع دعم احتياطي فائق القوة عبر **UDP Broadcast** على المنفذ `8889` لضمان الاكتشاف حتى لو قام راوتر الـ Wi-Fi بحجب حزم الـ Multicast.
2. **اتصال مستقر ومستقل بعد الاكتشاف:**
   - خادم محلي مدمج WebSocket / TCP عبر `org.java-websocket:Java-WebSocket:1.5.6` على المنفذ `8888`.
   - قناة الاكتشاف منفصلة تماماً عن قناة البيانات والرسائل.
3. **أوضاع التشغيل:**
   - **TV / Host:** إنشاء غرفة باسم "NeoStrike Room" واستقبال اتصالات الهواتف وعرض اللاعبين المتصلين واستقبال رسالة "TEST" وإرسال "HOST TEST".
   - **Phone / Controller:** بحث تلقائي فوري عن الغرف، زر انضمام بدون طلب IP أو Port أو QR أو كود، إرسال "TEST" واستقبال "HOST TEST"، وزر Disconnect.
4. **لوحة تشخيص الشبكة (Network Diagnostics - 🔧):**
   - حالة الـ Wi-Fi، الـ IP المحلي، IP المستضيف، المنفذ، حالة الاكتشاف، عدد الغرف، حالة الاتصال، آخر رسائل مرسلة ومستقبلة، وسجل الأحداث الزمني.

## متطلبات التشغيل
- Android Studio Hedgehog (2023.1.1) أو أحدث.
- JDK 17.
- جهازان بنظام Android (مثلاً شاشة TV / تابلت + هاتف، أو هاتفين) متصلان بنفس شبكة الـ Wi-Fi، أو أن ينشئ أحدهما Portable Wi-Fi Hotspot ويتصل به الآخر (Offline بالكامل).

## طريقة الفتح والبناء في Android Studio
1. افتح Android Studio واختر **Open**.
2. اختر المجلد `android` في هذا المشروع.
3. انتظر اكتمال مزامنة Gradle (`Sync Project with Gradle Files`).
4. اختر الجهاز الأول (TV أو هاتف 1) واضغط **Run 'app'**.
5. اختر الجهاز الثاني (هاتف 2) واضغط **Run 'app'**.
6. في الجهاز الأول اختر **TV / Host** واضغط **[ إنشاء غرفة ]**.
7. في الجهاز الثاني اختر **Phone / Controller** وسيتم اكتشاف الغرفة فوراً؛ اضغط **[ انضمام ]**.
8. اضغط **[ SEND TEST ]** لتشاهد ظهور الرسالة على شاشة الـ TV فوراً.
